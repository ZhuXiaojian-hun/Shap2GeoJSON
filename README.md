# Shap2GeoJSON

将 Shapefile 行政区划文件**按指定属性列拆分**为一个个独立的小行政区划 GeoJSON 文件。

不是把整个图层转成一个文件，而是：用户在界面上从属性表**下拉选择一列**（如 `省`、`省级码`），
程序按该列每一行的取值生成一个独立的 GeoJSON 文件（如 `北京市.geojson`、`110000.geojson`）。

## 运行环境

- Windows + Python 3（已自带 tkinter）
- 必需：无（核心读取器为纯标准库实现，零第三方依赖）
- 可选增强：
  - `pyproj`：当源文件坐标系不是 WGS84 时自动转换（本项目测试数据本身就是 WGS84，可不装）
  - `shapely`：自动修复自相交、退化的无效几何（建议安装）

当前开发机已安装 `pyproj`、`shapely`。

## 直接使用 EXE（推荐）

无需安装 Python，双击 **`dist\Shap2GeoJSON.exe`** 即可打开界面，界面提供：

- **输入**：选择 `.shp` 文件
- **选择列名**：从属性表字段下拉选择拆分依据
- **输出**：选择输出目录

### 重新打包 EXE

双击 **`build_exe.bat`**（内部调用 `build_exe.py`；需已安装 `pyinstaller`、`pyproj`、`shapely`），
完成后生成单文件 `dist\Shap2GeoJSON.exe`。

也可直接用命令行重建：

```
python build_exe.py
```

### 界面列名示例

`拆分列名` 下拉框会内联显示每条列的首条数据，例如 `省    （示例：北京市）`，
方便确认列的内容；程序内部会自动还原为真实列名。

### 命令行模式（可选，自动化用）

```
Shap2GeoJSON.exe <shp文件> <列名> <输出目录> [--precision 6] [--simplify 100] [--keep-crs] [--no-repair] [--no-csv] [--no-preview] [--open-preview]
```

`--simplify` 为几何简化容差（米），`0` 表示不简化，默认 `100`。
`--no-csv` 可关闭属性表导出（默认开启）。
`--no-preview` 关闭预览页生成；`--open-preview` 生成后用浏览器打开（默认只生成不打开）。


## 使用步骤

1. 双击 **`app.pyw`**（或命令行 `pythonw app.pyw`）启动界面。
2. 点击【浏览...】选择 `.shp` 文件（同目录的 `.dbf`、`.prj` 会被自动读取）。
3. 在【拆分列名】下拉框中选择要作为拆分依据的列（如 `省`）。
4. 选择【输出目录】（默认在 shp 同级的 `<文件名>_geojson` 文件夹）。
5. 按需调整选项，点击【开始转换】。日志区会实时显示进度。

### 界面选项

| 选项 | 说明 |
|------|------|
| 几何简化(米) | **控制文件大小最有效**。按容差对多边形/线做 Douglas-Peucker 抽稀，`0`=不简化，默认 `100`（米）。旁有预设按钮：不简化 / 50 / 100 / 200 / 500 |
| 坐标小数位 | 输出坐标保留的小数位数，默认 6（WGS84 下约 0.1 米）。数字越小文件越小，但影响有限 |
| 输出为 WGS84 | 勾选后，若源坐标系不是 WGS84 则自动转换；未勾选则保持原始坐标系 |
| 修复无效几何 | 用 shapely 修复自相交、坐标取整导致的退化环等问题，保证输出合法。默认开启 |
| 同时导出属性表 CSV | 在输出目录额外生成与输入同名的 `.csv`（UTF-8 BOM，Excel 可直接打开），含表头与全部属性记录。默认开启 |
| 生成预览页并自动打开 | 转换后在输出目录生成 `preview.html` 并用默认浏览器打开（见下）。默认开启 |

> 文件大小主要取决于**顶点数量**。以 34 个省级数据为例：默认 6 位小数约 16 MB，
> 加 100 米简化后降到约 3.4 MB（约 -79%），而省级/国家级视图下几乎看不出差异。

## 输出格式

每个文件都是一个只包含一个要素的 `FeatureCollection`：

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": { "省": "北京市", "省级码": "110000", "...": "..." },
      "geometry": { "type": "Polygon", "coordinates": [[[ ... ]]] }
    }
  ]
}
```

- 文件名取自所选列的值，自动过滤 `\ / : * ? " < > |` 等非法字符；
- 取值为空时命名为 `feature_序号`；
- 出现重名时自动追加 `_2`、`_3` 等后缀；
- 属性表中的全部字段都会保留。

输出目录中还会生成一个属性表 CSV（文件名与输入的 shp 相同，如 `2024年初省级.csv`），
首行为字段名，其后为全部记录，编码为 `UTF-8 BOM`，可直接用 Excel 打开。

## 查看 / 预览 GeoJSON

### 内置预览页（推荐）

转换完成后会在输出目录生成 **`preview.html`** 并自动用默认浏览器打开；
界面上的【预览输出】按钮可随时再次打开。

- **完全离线、单文件**，不联网、不依赖任何第三方库；
- 自动缩放到全部要素，支持**滚轮缩放 / 拖拽平移 / 复位视图**；
- 每个行政区按列值着色，**鼠标悬停高亮并显示名称，点击查看完整属性**；
- 左侧列表可筛选、点击定位到某个行政区。

> 预览页大小约等于该次输出的 GeoJSON 总量（默认简化下约 3 MB）。

### 外部工具（可选）

| 工具 | 说明 |
|------|------|
| **QGIS** | 最专业、离线；把 `.geojson` 拖进去，可查属性表 |
| **mapshaper.org** | 浏览器打开，拖入即看，还能再简化/导出 |
| **geojson.io** | 浏览器拖放即看，可编辑 |

## 命令行调用（可选）

```python
import converter

converter.convert(
    r"D:\data\2024年初省级.shp",
    column="省",              # 拆分列
    out_dir=r"D:\out",
    precision=6,              # 坐标小数位
    keep_crs=False,           # False = 输出 WGS84
    repair=True,              # 修复无效几何
    simplify_meters=100,      # 几何简化容差（米），0=不简化
    export_csv=True,          # 同时导出属性表 CSV
)
```

## 文件说明

| 文件 | 作用 |
|------|------|
| `dist\Shap2GeoJSON.exe` | 打包好的单文件程序，双击即可运行 |
| `build_exe.bat` | 重新打包 EXE 的脚本（双击即可） |
| `build_exe.py` | 打包逻辑（PyInstaller 参数，bat 调用） |
| `main.py` | 程序入口：图形界面 + 命令行模式 |
| `app.pyw` | 双击启动器（开发时用，调用 `main.py`） |
| `converter.py` | 转换核心：读取、拆分、可选投影转换与几何修复、写出 GeoJSON |
| `preview.py` | 生成自包含离线预览页 `preview.html` |
| `shapefile_reader.py` | 纯标准库的 Shapefile 读取器（`.shp` 几何 / `.dbf` 属性 / `.prj` 坐标系） |

## 已知说明

- 属性表编码自动识别（优先 UTF-8，其次 GBK）。
- 支持 Point / MultiPoint / Polyline / Polygon / MultiPolygon 等几何类型；行政区划以多边形为主。
- 多边形内外环按 ESRI 方向规则（外环顺时针）自动区分，并正确分配内环（空洞）。
